# 🚙 자동차 경주

## 기능 목록

### 1. 사용자 입력 받고 처리하기

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
2
```

#### ✅ 기능

- [x] 경주할 **자동차 이름 목록**을 입력받는다.
  - 입력 예시: `pobi,woni,jun`
  - 각 이름은 `trim()`을 적용해 공백을 제거한다.
- [x] **시도 횟수**를 입력받는다.
  - 입력 예시: `5`
- [x] 입력받은 값을 바탕으로 유효성 검사를 수행하고, 통과 시 데이터를 반환한다.

#### ❎ 예외

- [x] 자동차의 이름이 5자 초과인 경우 &rarr; `[ERROR] 자동차의 이름은 5자 이하여야합니다.`
- [x] 자동차의 이름이 중복되는 경우(예: `pobi, woni, pobi`) &rarr; `[ERROR] 자동차 이름은 중복될 수 없습니다.`
- [x] 자동차 이름에 허용되지 않는 문자가 포함된 경우(알파벳, 한글, 숫자, 공백 이외) &rarr; `[ERROR] 자동차 이름에는 허용되지 않는 문자가 포함되어 있습니다.`
- [x] 입력 문자열 처리 후, 유효한 이름이 하나도 없는 경우(즉, 이름 배열의 길이가 0인 경우) &rarr; `[ERROR] 경주할 자동차 이름은 최소 1개 이상 입력해야 합니다.`
- [x] 시도 횟수가 숫자가 아닌 경우 &rarr; `[ERROR] 시도 횟수에 숫자를 입력해야합니다.`
- [x] 시도 횟수를 입력할 때 1 미만의 경우 &rarr; `[ERROR] 시도 횟수는 1 이상이어야 합니다.`
- [x] 시도 횟수에 빈 문자열이 입력된 경우 &rarr; `[ERROR] 시도 횟수를 입력해야 합니다.`

### 2. 경주 시뮬레이션 및 차수별 결과 출력

```
실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --
```

#### ✅ 기능

- [x] **`Car` 클래스 생성**
  - 각 자동차는 이름(name)과 현재 위치(position)을 가진다.
  - `move()` 메서드: 무작위 값이 4 이상일 경우 `position`을 +1 증가시킨다.
- [x] **`RacingGameController` 클래스 생성**
  - InputView로 입력받고 Validator로 검증하는 흐름을 제어한다.
  - 시도 횟수만큼 `RacingGame.runTurn()`을 반복 실행하는 흐름을 제어한다.
- [x] **`RacingGame` 클래스 생성**
  - 입력받은 자동차 목록을 기반으로 `Car` 객체 배열을 생성한다.
  - 입력받은 시도 횟수만큼 반복 실행한다.
  - 각 턴마다 모든 자동차의 이동을 수행한다.
- [x] **무작위 값 생성**
  - `MissionUtils.Random.pickNumberInRange(0, 9)`를 통해 난수를 생성한다.
- [x] **경주 결과 저장 및 출력**
  - 매 시도마다 각 자동차의 이름과 이동 거리를 출력한다.
  - 이동 거리는 `-` 기호로 시각화한다.

### 3. 최종 우승자 판별 및 결과 출력

#### ✅ 기능

```
최종 우승자 : pobi, jun
```

- [ ] 경주에 참여한 모든 자동차 중 **가장 멀리 이동한 거리**를 계산한다.
- [ ] 가장 멀리 이동한 거리에 위치한 자동차들을 우승자로 선정한다.
- [ ] 우승자들의 이름을 쉼표(,)로 구분하여 지정된 형식으로 최종 우승 결과를 출력한다.
